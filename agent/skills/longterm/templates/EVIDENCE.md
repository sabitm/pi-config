# Evidence

Append only. One entry per observation. Other files refer to E-ids and do not repeat the details.
An observation states only what a command, capture, test, or user report shows.
Put interpretations, hypotheses, and decisions in DECISIONS.md.

Format:
E<n> <YYYY-MM-DD HH:MM> <title>
- Observation: <facts only>
- Source: <command, file path, or "user report">
- Limitation: <missing controls, sample size, conditions not tested, conflicting evidence, or none known>
